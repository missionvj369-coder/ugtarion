# About

**Universal Guard Trust (UGT)** is building an open architecture for continuous civilizational learning and creation.

The central direction is:

**Human Evolution → Integrated Intelligence → Human Flourishing → Civilization Transformation → Conscious Civilization → Heaven on Earth**

This repository contains the technical foundation for UGT's evolving open-source systems, experiments, documentation and infrastructure.

UGT does not claim that civilization has already been solved.

The objective is to build systems through which people can:

**Understand → Connect → Create → Test → Measure → Learn → Share → Adapt → Create Again**

# Run Locally

## Prerequisites

* Node.js
* npm

## Install

```bash
npm install
```

## Environment

Create:

```text
.env.local
```

Add the required Gemini configuration used by the application:

```text
GEMINI_API_KEY=your_key_here
```

Never commit `.env.local` or API keys to GitHub.

## Development

```bash
npm run dev
```

Then open the local development URL shown by the application.

# Principles

## Human dignity

People are never merely optimization targets, resources or data points.

## Human agency

Technology should expand meaningful human capability and choice.

## Evidence

Distinguish evidence from interpretation, hypothesis and aspiration.

## Openness

Where appropriate, methods, knowledge and tools should be inspectable and reusable.

## Accountability

Important systems should remain understandable, auditable and correctable.

## Ecological responsibility

Human systems operate within living ecological systems.

## Pluralism

Different cultures, disciplines and perspectives can contribute knowledge without requiring one system to own human meaning.

## Continuous learning

Failure can become valuable knowledge when it is documented honestly.
